# Frontend Mentor – Recipe Page

This is my solution to the **Recipe Page** challenge on Frontend Mentor.  
The goal was to build a responsive recipe layout using semantic HTML and modern CSS.

## Links
- Live Site: https://kshitizzanand.github.io/frontend-mentor-recipe-page/
- Solution: https://www.frontendmentor.io/solutions/css-and-html-semantics-and-media-queries-9XCuMDb300

## Built with
- Semantic HTML5
- CSS (mobile-first)
- CSS variables as design tokens
- Flexbox (minimal use)

## What I learned
- How to think in terms of **flow instead of fixed widths**
- Mobile-first layout using padding and `max-width`
- Using CSS variables to represent design tokens
- Handling full-width images with padded content
- Basic Git and GitHub Pages deployment
